# Time Series Analysis and Forecasting

This repository presents time series projects using Switzerland’s economic turnover data, focusing on both model understanding and forecasting.


## Project 1: Time Series Analysis of Switzerland Economic Turnover in AR(2) and Simulation Study [![Project 1](https://img.shields.io/badge/Project1-Modeling-blue)](https://github.com/seoyeon3/Time-Series-Projects/blob/main/Project1%3A%20Time%20Series%20Analysis%20of%20Switzerland%20Economic%20Turnover%3A%20AR(2)%20and%20Simulation%20Study.pdf)

**Problem**  
Time series data often contain trend and seasonal patterns, making it necessary to understand the underlying structure before building a model.

**Approach**  
- Analyzed trend and seasonality in the data  
- Applied log transformation and differencing to achieve stationarity  
- Used ACF and PACF to identify model structure  
- Built ARMA models and selected the final AR(2) model based on statistical significance  



## Project 2: Time Series Forecasting and Evaluation [![Project 2](https://img.shields.io/badge/Project2-Forecasting-green)](https://github.com/seoyeon3/Time-Series-Projects/blob/main/Project2%20Report.pdf)


**Problem**  
Accurately forecasting future values requires capturing temporal dependencies and validating model performance through rigorous diagnostics.

**Approach**  
- Built ARIMA and SARIMA models to forecast future turnover values  
- Compared models using AIC/BIC and error metrics  
- Performed residual diagnostics (ACF, Q-Q plot, Ljung-Box test)  
- Generated 12-month forecasts and evaluated prediction performance  
- Applied smoothing and spectral analysis to further analyze time series behavior
